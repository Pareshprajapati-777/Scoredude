# Scoredude

A modern, dynamic student evaluation and scoring platform with tactile interactions, real-time analytics, and SQLite persistence.

## Features
- **Adaptive Evaluation Interface**: Rate candidates across dynamic customizable pillars (0-10 scale).
- **Auto-Calculations**: Real-time percentage, weighted totals, and automatic letter grading (A+, A, B+, B, C, F).
- **Emil Kowalski Design**: Tactile micro-interactions, smooth spring-animated tabs, responsive feedback, and modern aesthetics.
- **Directory Management**: Full CRUD for candidates and scoring categories.
- **Evaluation History & Printable Scorecard**: Filter by grade/batch, export CSV, and print accredited scorecards.
- **SQLite Database**: Full data persistence in local `score.db`.

## Tech Stack
- **Frontend**: React, Vite, Tailwind CSS, Framer Motion, Lucide Icons, Canvas Confetti
- **Backend**: Express.js, SQLite3 (`score.db`)
- **Design Philosophy**: Emil Kowalski Design Engineering & Tactile Feedback

## Quick Start
```bash
# Install dependencies
npm install

# Start development server
npm run dev
```
